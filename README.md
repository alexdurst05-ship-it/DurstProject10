# Tax Calculator

## What It Does

This is a tax calculator that lets users enter their income and calculates how much tax they owe using three different tax brackets.

## Built With

- Python
- Flask
- HTML
- CSS

## How to Run It

1. Open the project folder in VS Code.
2. Install Flask using `python -m pip install flask`.
3. Run the program using `python app.py`.
4. Open http://127.0.0.1:5000 in your browser.
5. Enter your income and click Calculate.

## Screenshot Description

The home page shows a Tax Calculator title with a form where users can enter their income. After clicking Calculate, the result page shows the income and the calculated tax with a dollar sign and two decimal places.
